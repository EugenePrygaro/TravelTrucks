TravelTrucks 🚐

TravelTrucks is a modern web application designed to help users easily browse, filter, and rent camper trucks for their outdoor adventures and road trips. Users can explore a comprehensive catalog of campers with seamless pagination, filter vehicles by various features and specifications, and view detailed information including reviews, features, and booking details.

✨ Features
Camper Catalog: Browse a list of available camper trucks with smooth infinite scrolling and pagination.

Advanced Search & Filtering: Filter campers by location, body type (alcove, panel_van, integrated, semi_integrated), transmission (automatic, manual), and engine type (diesel, petrol, hybrid, electric).

Camper Details Page: Explore individual camper specs, features, photo gallery, and real user reviews.

Form Handling & Validation: Interactive search sidebar with instant resetting and validation.

Interactive Image Galleries: Smooth image swiping powered by Swiper.

Responsive Design: Optimized layout for seamless navigation across devices.

🛠️ Tech Stack

Framework: Next.js (App Router) & React

Language: TypeScript

Data Fetching & State: TanStack Query (React Query)

HTTP Client: Axios

Form Management: Formik & Yup

Carousels & Sliders: Swiper

UI Notifications: react-hot-toast

Styling: CSS Modules

🚀 Getting Started
Follow these steps to set up and run the project locally on your machine.

Prerequisites
Ensure you have Node.js installed on your machine.

Installation

Clone the repository:

git clone https://github.com/your-username/travel-trucks.git
cd travel-trucks

Install dependencies:

npm install

Set up Environment Variables:

Create a .env.local file in the root directory and add your API endpoint:

NEXT_PUBLIC_API_URL=https://your-api-url.com

Run the development server:

npm run dev
Open in Browser:
Navigate to http://localhost:3000 to view the application in your browser.
